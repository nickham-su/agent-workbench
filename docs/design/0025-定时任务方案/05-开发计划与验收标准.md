## 阶段计划

### 阶段 A：Shared 契约、轻量持久化与纯时间核心

| 项目 | 必须完成 |
|---|---|
| Shared 契约 | 新增 `scheduled-tasks.ts`，定义 Task、Execution、UTC schedule、PUT/POST/API query、cursor、错误类型；从 shared index 导出。 |
| Schema | 在非 Agent 基础 schema 路径幂等建 Task/Execution、完整 CHECK、scheduled slot unique index、活动态 unique index 和域内 FK；不得改 `AGENT_SCHEMA_VERSION`/Agent 分类。 |
| Store | 实现 Workspace join 边界、Task/Execution CRUD、声明事务、快照、cursor 编解码和安全原因码。 |
| Calculator | 实现无副作用 `normalizeSchedule()`、`nextRunAt()` 与 local/UTC adapter 的共享测试向量。 |

**依赖**：无。  
**完成定义**：全新 SQLite 与已有 Agent schema 数据库均能建表，且不调用 Agent destructive rebuild；Task/Execution 约束、cursor 和纯函数测试通过。

## 测试与验收矩阵

### 纯函数和 local/UTC adapter

| 场景 | 必须断言 |
|---|---|
| hourly/daily 多值 | 输出严格未来；无序/重复输入规范化；恰好到点返回下一个未来 slot。 |
| weekly 多 slot | weekday 统一 `0=周日..6=周六`；跨 UTC 日不产生额外组合。 |
| UTC+05:30 | daily `00:15` 与 weekly 跨日转换符合规范向量。 |
| UTC+05:45 | weekly 周一 `00:15` 转为 UTC 周日 `18:30`。 |
| UTC-07:00 | 周六 `23:30` 转 UTC 周日 `06:30`。 |
| 单次 offset | 一次提交只读取一次 `getTimezoneOffset()`；不得按未来日期取 DST offset。 |
| DST/换时区 | 固定 UTC 规则回显允许偏移；重新保存按新 offset 重写。 |
| weekly 不可因式分解 | 必须进入 pair editor，保存不生成额外 slot。 |
| 预览 | 摘要按单一 offset；三次 UTC instant 各自按浏览器实际时区格式化。 |

### SQLite、约束、API 与分页

| 场景 | 必须断言 |
|---|---|
| 迁移隔离 | 已有 Agent 数据时初始化 scheduled 表不触发 `rebuildAgentDomain()`，Agent 数据保留。 |
| Task CHECK/名称 | enabled/nextRunAt、trigger/source nullability、Prompt 限制均拒绝非法组合；`normalizeScheduledTaskName()` 将 tab/LF/CR 等连续 `\s` 空白压缩为空格并 trim，得到确定名称；仅空白输入、压缩后残留 NUL/退格/C1 控制字符及超过 100 Unicode code points 必须拒绝。 |
| Execution CHECK | status 枚举、scheduled/manual scheduledFor、skipped Session/Run/startedAt、非 skipped sessionId、finishedAt/活动态组合均被 SQLite 拒绝。 |
| 索引 | 同 `(taskId,scheduledFor)` 仅一条 scheduled execution；同 Task 至多一条 starting/running；Task 删除 cascade Execution。 |
| Workspace 边界 | Execution 不存 workspaceId；所有 execution 操作经 Task join + workspace 条件，跨 Workspace 不可读取/修改。 |
| Task cursor | `(enabled DESC,updatedAt DESC,id DESC)` 无重复/漏项；q/status 指纹不匹配、篡改、版本错误均 `CURSOR_INVALID`。 |
| Execution cursor | `(createdAt DESC,id DESC)` 无重复/漏项；result/triggerType 指纹不匹配均 `CURSOR_INVALID`。 |
| 搜索 | q trim 空等于未传、最多 100 code points、仅名称、ASCII 不区分大小写、过滤后分页。 |
| 历史筛选 | failed 包含 `failed_to_start`，不含 cancelled；starting/running/cancelled 仅 result=all。 |
| PUT schedule 相等 | 规范化排序去重后 schedule 深度相等时，名称/Prompt/Agent/trigger/source 变更均保留原 nextRunAt。 |
| PUT schedule 变化 | enabled 时以事务 now 替换为新规则的严格未来 slot，旧未声明 slot 无 execution；paused 时始终 null，恢复启用按新规则计算。 |
| PUT 与 Scheduler 竞态 | 已声明 execution snapshot 不变；非 schedule PUT 先提交则 Scheduler 按新配置/旧 nextRunAt 声明，schedule PUT 先提交则旧 slot 被替换。 |
| 来源校验 | Drawer ID 改变即失效；POST/PUT/触发均重新校验；响应仅 500 code point 纯文本摘要。 |

### 调度、Run、手动执行与重启

| 场景 | 必须断言 |
|---|---|
| Scheduler 首扫 | `starting` phase 对旧 slot 只推进 future，不写 execution。 |
| running 多 slot 积压 | 每 Task 每 tick 最多处理旧 nextRunAt 一条记录，再直接推进到 scanNow 后首个 future；中间 slots 无记录。 |
| 两个 tick | 同一 slot 仅一条 execution；活动时自动写 skipped、手动 409 无记录。 |
| Snapshot/标题 | 声明后编辑 Task，既有 execution 保留完整规范化 taskName/Prompt/Agent/source snapshot；详情显示完整名称，Session 标题通过权威构造函数得到截断后的 `<prefix> · 定时任务`。 |
| 标题边界与兼容性 | 覆盖 CJK、emoji、100 code points、50 标题边界和超长前缀截断；tab/LF/CR 被压缩为空格、仅空白被拒绝、NUL/退格/残留 C1 控制字符被拒绝。验证 `normalizeManualSessionTitle()` 保持相同控制字符处理顺序；若升级长度计数，验证其改为 code point 计数但不改变手动标题控制字符兼容语义。前端不得自行截断。 |
| expected-ID 创建 | 同一权威构造标题、Workspace、kind、Fork 血缘和输入完全一致时幂等；ID 被非预期 Session 占用时 `session_id_conflict`，不得直写/覆盖。 |
| 前置失败 | Run 未创建的 Agent/Fork/Session/Prompt 失败为 `failed_to_start`。 |
| 确定 enqueue 拒绝 | Run 持久化但可证明未进入 work 时为 `failed_to_start`。 |
| enqueue unknown | `AGENT_WORKER_ENQUEUE_UNKNOWN` 保持 starting、返回 202，随后可用 session+clientRequestId 对账；不得立即失败。 |
| 快速终态 | Run 在 execution 回写前 completed/failed/cancelled 时，允许 starting 直接按 Run 收敛。 |
| Worker 已进入 work 后失败 | 映射 `failed`，而不是 failed_to_start。 |
| API 重启 | 有 runId 只对账；无 runId 但发现同 clientRequestId Run 时补关联；陈旧 starting 无 Run 时 failed_to_start，不重发 Prompt。 |
| 手动确定失败 | manual execution 先持久化，随后 failed_to_start；4xx/503 error details 含 executionId，历史保留。 |
| 暂停/删除/fence | 暂停不停止 Run但允许手动；活动 Task 删除 409；fence 后不声明，删除后 Task/Execution 均清理。 |

### Fork 消息图

| 场景 | 必须断言 |
|---|---|
| 本 Session 历史分支 | `target.origin_session_id=sourceSessionId` 的 Revert 离开 current head 分支可按锚点处理。 |
| Fork Session 继承消息 | target 位于固定 `forked_from_message_id` 祖先链时可作为来源。 |
| 无关同 Workspace 消息 | 未满足上述两条成员关系时拒绝。 |
| 跨 Workspace 消息 | 统一拒绝且不返回标题/摘要。 |
| 继续对话/Revert/运行中 | 不依赖 source 当前 head/revision/idle。 |
| Compaction | retained/context anchor 可解析时成功；不可恢复时 failed_to_start。 |
| 类型与完整性 | 未终态、工具未完成、图断裂/循环均 fail-close，禁止 fallback。 |

### 前端与端到端交互

| 场景 | 必须断言 |
|---|---|
| Dock/UI | 工具入口、左右布局、无标题数量/更多菜单/Provider-Model/时区/Cron/文件提示。 |
| 列表 | q 搜索、三种状态筛选、服务端排序、运行时长、仅 scheduled-skipped 警告。 |
| 历史 | result/triggerType 筛选、状态展示、skipped hover/focus Tooltip、cursor 翻页。 |
| Drawer | new/fork 切换、ID 输入校验失效、未校验不能保存、ready Agent、weekly pair 降级。 |
| Session | 最近执行/历史跳转；Session 已删除显示确定错误。 |
| 手动运行 | unknown 文案为“已提交，正在确认运行状态”；确定失败刷新历史。 |
| 时间同步 | 固定 30 秒请求；可见时按基线每秒显示；不可见可暂停；恢复可见立即请求且成功重置周期。RTT/offset 映射 normal/warning/uncertain，失败 `<120s` 为 uncertain 并显示“正在重新同步”，从未成功或 `>=120s` 为 unavailable。 |

## 代码审查标准

| 审查项 | 必须满足 |
|---|---|
| 变更范围 | 不修改 `.prototype`、归档初稿、无关 analytics/API 文件或用户已有变更。 |
| 迁移 | scheduled 表不进入 Agent destructive rebuild；Task/Execution SQL CHECK 与本文一致。 |
| 安全边界 | 所有 execution Workspace 操作经 Task join；无跨 Workspace 信息泄露；摘要/日志不含敏感内容。 |
| 执行边界 | 不直写 agent_run/session，不直调 Worker；expected-ID 仅在 Agent 内部接口实现。 |
| 调度 | phase、单 slot 推进、partial unique、active skip 和停机不补跑均由后端/DB 保证。 |
| 时间 | 固定 UTC、单 offset、weekday 编码、weekly slot/pair 降级均一致。 |
| Fork | 成员关系算法、图校验、fail-close 且公开 Fork 行为未放宽。 |
| 恢复 | Run 持久化状态/phase 为权威；unknown 不误判失败；不重发 Prompt。 |
| 产品契约 | PUT 全量/规范化 schedule 相等性与相位保持、启停 action、搜索筛选 cursor、warning 投影、手动 202/确定失败均一致。 |
| 生命周期 | 完整 taskName snapshot 与权威 Session 标题、Task 删除 cascade execution 但保留 Agent 数据、Workspace fence/清理顺序正确。 |

## 最小验证命令

在仓库根目录按改动范围执行：

```bash
npm run build -w packages/shared
npm run typecheck -w apps/api
npm run typecheck -w apps/web
```

阶段 E 完成后执行：

```bash
npm run typecheck
npm test -w apps/api
npm test -w apps/web
npm run build
```

若命令被无关既有问题阻断，验收记录必须区分本功能结果与既有失败，附可复现命令和脱敏错误摘要；不得借此跳过本功能测试。
