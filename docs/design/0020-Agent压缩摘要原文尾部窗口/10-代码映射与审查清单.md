## 审查清单

### 契约与Schema

- [ ] Compaction严格，其他四类保持宽约束且禁retainedFrom。
- [ ] retained FK `ON DELETE RESTRICT`、null check、同Workspace trigger、不可更新trigger完整。
- [ ] `agent_run`有execution_phase、intended三元组、terminal result及完整phase/status/nullability/长度check。
- [ ] running只允许work_pending/work_in_progress/terminal_intent_persisted；terminal status只允许phase terminal。
- [ ] 全局registry是业务权威；API严格验证组合，unknown拒绝。
- [ ] 不存在session_run_state terminal result字段。
- [ ] schema semantics覆盖以上约束。

### Run终态与公共查询

- [ ] Run创建为work_pending，Worker真正开始后受保护原子转为work_in_progress。
- [ ] 旧completeRun契约/端点/API Client/completeRunFromWorker/包装层全部删除。
- [ ] 六个最终动作的method/path、严格request/response、token、ownership、phase与registry校验完整。
- [ ] 普通Assistant完成不写intent；终态Assistant在同一事务写Assistant、response tokens与intent。
- [ ] terminal Assistant拒绝ToolCall/ToolExecution，可带replay/reasoning；user/subtask成功码固定。
- [ ] runModelStep在流结束后按recognizedCalls、visible文本和空响应本地计数选择入口；前N-1空响应普通完成，第N次原子终态完成。
- [ ] 成功commitCompaction同一事务写CompactionMessage/TextPart、Session root/head与compaction_completed intent。
- [ ] 无产物Worker结果、manual no-op/blocked/failure、API取消、enqueue/startup failure独立写intent再convergence。
- [ ] `persistTerminalIntent`相同重放幂等、不同intent冲突；`convergeRunTerminal`不接收结果参数。
- [ ] convergence只读intended，严格按workspace/session/run origin范围，不触碰其他Run。
- [ ] completed intent 断言无streaming/nonterminal Message和queued/running ToolExecution；违反即data invariant且不idle。
- [ ] failed/cancelled分别收敛streaming Assistant；queued ToolExecution→cancelled，running→unknown，诊断语义正确。
- [ ] queued/running ToolExecution实际转态同事务写completedAt=convergence.updatedAt、status、updatedAt、updatedRevision，保留startedAt且不伪造/改写result/error；DTO准确暴露completedAt。
- [ ] artifact的updatedRevision/updatedAt/completedAt、Session revision、Run actual result/phase、intended清空与session_run_state idle同一事务。
- [ ] persistence返回transitioned/already_converged及finalStatus；重放校验artifact completedAt，绝不改写它。
- [ ] API cancel、enqueue/startup、Worker failure/cancel无其他artifact收敛权威；旧fail/cancel helper语义已迁移删除。
- [ ] 已terminal仅artifact/Run/Session/run state一致时幂等；残留矛盾或不同终态拒绝。
- [ ] Worker RPC、API cancel、enqueue failure、startup和Workspace deletion逐Run路径均进入唯一after-convergence后置函数。
- [ ] 每种成功convergence都清Run prompt static cache；仅transitioned发布既有`agent.run.completed.v1`且所有Run首入terminal覆盖。
- [ ] 事件发布失败只记录错误、不回滚；already_converged不补发；确认接受无outbox的best-effort漏送风险。
- [ ] SSE一次性、响应丢失重放无重复事件，既有飞书插件/通知订阅事件格式与无重复通知回归通过。
- [ ] terminal_intent_persisted仍对外running/null code；公共查询不暴露phase或intended。
- [ ] Worker/API允许提交子集明确并有测试。
- [ ] detail默认null，仅允许registry枚举键。
- [ ] 已终态相同结果幂等，不同结果拒绝。
- [ ] Runner terminal loop先intent后convergence；每阶段最多3个真实HTTP请求、合计最多6个、共享10秒、固定250ms退避。
- [ ] 原子terminal Assistant/compaction在work deadline内幂等重试，成功后不调用intent；首次convergence前新建10秒deadline，最多3次。
- [ ] 两个API Client policy均`maxRetries:0`，每次timeout裁剪到terminal-control剩余时间。
- [ ] startup recovery只按phase：intent persisted只converge；pending/in progress安全恢复或写startup failure intent。
- [ ] 工具完成后等待下一模型步骤的work_in_progress继续同一Run；不得以Assistant/Tool/Compaction artifact推断终态。
- [ ] registry没有已移除的旧控制面结算失败码；convergence失败保留原intent，startup继续convergence。
- [ ] 公共路径为`GET /api/agent/sessions/:sessionId/runs/:runId?workspaceId=...`。
- [ ] 校验Run与Session/Workspace ownership。
- [ ] 空Session compact同步400且不创建Run。
- [ ] pending tools稳定code存在。
- [ ] user/manual/subtask完整码表逐项存在，不使用“其他稳定码”。
- [ ] clientRequestId重放返回同一runId。
