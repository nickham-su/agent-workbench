# 验收标准与测试矩阵

[返回导航](00-文档导航.md)｜[接口契约](02-CLI与查询接口契约.md)｜[鉴权规则](03-鉴权续签与凭证缓存.md)

## 验收原则

- 本文是开发后的验收清单，不是已经通过的测试报告。
- 所有业务例子使用普通Session fixture，不设置日报或报告专用身份。
- 使用临时时钟、临时SQLite、临时用户配置根和临时认证数据，禁止读取真实Cookie、用户会话或运行数据库。
- CLI正常/错误输出分别断言stdout/stderr和退出码，不能仅断言文本包含某个词。
- 文档契约、单测、API集成、CLI真实HTTP和Docker/Worker人工验证分别留证据。

## API全量查询与时间

| 案例 | 数据/条件 | 必须结果 |
|---|---|---|
| Workspace缺失 | 请求合法但Workspace不存在 | 404 WORKSPACE_NOT_FOUND |
| 零匹配 | Workspace有效，无匹配 | 200，total0，items[] |
| 两端边界 | 记录恰好updatedFrom、updatedTo | 都包含 |
| 边界外 | from-1ms、to+1ms | 都排除 |
| 时钟一致 | 可变mock clock | now仅取一次，返回范围与SQL范围一致 |
| 时区/夏令时 | 客户端换时区，同整数秒 | 筛选相同，CLI显示UTC Z |
| 主/子过滤 | primary、subtask各含idle/running | 三种kind与三种status组合正确 |
| 页面关闭 | 关闭primary、未打开subtask | 新query仍包含；旧tabs行为保持 |
| 空会话/标题 | head为空、title空或默认名 | 可以匹配，无额外“continuable”约束 |
| 超旧页上限 | 一次匹配150条以上 | 全部返回，total等于items长度，无cursor/limit |
| 相同时间排序 | 多条相同updatedAt | 按id二进制降序，不依赖locale |
| 当前状态 | 上次Run failed/cancelled但当前idle | 返回idle，不冒充任务成功或失败 |
| 状态损坏 | 候选缺RunState或status非法 | 500 STATE_INVALID，不隐藏或补idle；status具体过滤也不能掩盖 |
| 非法时间/数值 | 无法安全表示的DTO数值 | 500 STATE_INVALID，不输出舍入或部分成功 |
| 公开认证 | auth开/关、有效/缺失/过期Cookie | 与现有公开鉴权一致，不接受内部token替代Cookie |

其中STATE_INVALID的完整code为`AGENT_SESSION_QUERY_STATE_INVALID`，参数错误完整code为`AGENT_SESSION_QUERY_INVALID`。

## 累计消息指标

| 案例 | 数据/操作 | 必须结果 |
|---|---|---|
| 无消息 | 原生消息0条 | 两项都0，Session不被漏掉 |
| 基础计数 | 2个completed user、3个completed assistant | 返回2/3 |
| 类型排除 | system/runtime/compaction各若干 | 不增加两项 |
| 状态排除 | streaming/failed/cancelled/superseded assistant | 不计；不把所有assistant行当完成响应 |
| 源归属 | Fork引用源历史，自身少量新增 | 只算自身origin_session_id |
| 自动压缩 | 同会话提交compaction并移动根 | 原有两项不减少，compaction不加数 |
| 手动压缩 | 创建手动压缩Run与summary | 不用Run数或summary当user/assistant计数 |
| 回滚 | 指针回退，原生completed记录仍保留 | 累计数保持，而非当前分支长度 |
| 失败任务 | Run失败前存在completed assistant | 这些completed消息继续计入 |
| 中间响应 | completed assistant含工具调用 | 一条消息计一次，不按tool数量放大 |
| 期间独立 | Session最近更新，旧消息在窗口前 | 仍计算全部原生累计，不给Message套窗口 |
| 跨Workspace | 其他Workspace及不同origin有消息 | 不污染目标计数 |
| 不重复聚合 | 多Session、多种消息 | 无JOIN乘法，空消息补零 |
| 读侧边界 | fixture无Parts/Run/Analytics | 新查询仍成功，不读正文或模型链 |
| 不自动筛选 | 低计数或任意名称Session | 仍返回，不跳过短会话或业务名称 |

## Cookie验证与续签

采用确定时钟，全部Cookie用临时测试密钥生成。

| 案例 | 条件 | 必须结果 |
|---|---|---|
| 普通阈值外 | 剩余6h+1ms | 无续签Set-Cookie |
| 普通阈值 | 剩余6h、6h-1ms且未过期 | 新24h窗口，无Max-Age |
| 长阈值外 | 剩余7d+1ms | 无续签 |
| 长阈值 | 剩余7d、7d-1ms且未过期 | 新30d窗口，Max-Age2592000 |
| 过期边界 | exp=now或更早 | 401，无续签 |
| 旧v1 | 现有24h/30d格式 | 正常认证，识别正确，不需重新login |
| 自定义有效TTL | 非标准窗口但签名有效 | 维持认证成功，不续、不升级 |
| 伪造 | 签名错误、版本错误、时间字段非法 | 拒绝，无Set-Cookie |
| 属性 | Secure开/关、普通/长 | 保持HttpOnly/Lax/Path；普通不加Max-Age |
| 路由排除 | health/login/internal/analytics signal | 普通续签hook不追加；login自签正常 |
| 错误业务 | 普通认证成功后400/403/404/500 | 达阈值仍续签，不改业务状态/响应body |
| auth关闭 | 无Cookie、旧Cookie | 不产生续签，不影响免认证业务 |
| 升级/SSE | WebSocket101、首次SSE头部 | WS不续；SSE仅首次普通认证头部可续 |
| 多Cookie头 | 业务已有其他Cookie/同名Cookie | 其他保留，同名不重复覆盖 |
| 同时续签 | 两请求接近时刻 | 都合法，接受轻微覆盖，不建立锁 |
| 重启/密钥变更 | 相同密钥重启、改变密钥 | 前者未过期继续有效；后者旧签名失效 |
| 轮询 | 阈值外/内连续业务请求 | 外不重复签；内签后恢复较长窗口；轮询算活跃 |

## CLI登录、缓存和响应处理

| 案例 | 条件 | 必须结果 |
|---|---|---|
| 鉴权关闭初始化 | health.authEnabled=false，无TTY且无stdin选项 | 先health、退出0，不消费stdin、不login，保存origin+cookie null；不能前置退出2 |
| 鉴权关闭有stdin选项 | authEnabled=false且指定token-stdin，输入流监测读取次数 | 不读取stdin，仍正常保存无Cookie配置 |
| TTY登录 | 正确token，正常服务器 | 隐藏输入，remember true，退出0，仅缓存Cookie |
| 认证开启非交互无stdin选项 | health.authEnabled=true且无TTY、无stdin选项 | health完成后退出2，不挂起、不读取环境token、不POST login |
| stdin登录 | 单行LF/CRLF | 去一末尾换行，保持其他字符，不记录token |
| 非法输入 | 空、多行、>64KiB、取消 | 退出2，旧配置保持 |
| 错误登录 | 401、缺Cookie、坏响应、网络失败 | 对应退出码，旧配置保持，无凭证输出 |
| origin变化 | 重新login另一个origin | 先无旧Cookie请求，成功后替换配置 |
| 缺配置/坏配置 | 不存在、坏JSON、版本/字段非法 | 退出3，不联网，不部分恢复 |
| 配置读权限 | 当前用户不可读 | 退出3，安全诊断 |
| 初次写权限 | 目录/文件不可写 | 退出7，不输出登录成功，不破坏旧文件 |
| 原子性 | 注入写/rename失败 | 旧配置完整；临时文件尽力清理 |
| 文件权限 | POSIX创建目录/文件 | 0700/0600；非POSIX记录适用限制 |
| cookie null查询 | 有origin，认证关闭 | 可成功，不在本地阻断 |
| auth后来开启 | cookie null查询 | 服务端401，退出4，提示login而不自动交互 |
| 过期/密钥改变 | 旧Cookie | 401退出4，不隐式保存长期token刷新 |
| 阈值外 | API无Set-Cookie | 不写缓存文件 |
| 续签成功 | 2xx+合法Set-Cookie | 更新后才输出业务结果 |
| 续签写失败 | 2xx+写/rename失败 | 退出7，stdout无成功内容 |
| 写失败与DTO失败组合 | 2xx+有效续签+写失败+无效业务DTO/JSON | 先续签写入，退出7、不继续业务校验，stdout为空 |
| 写成功与DTO失败组合 | 2xx+有效续签+写成功+无效业务DTO/JSON | 退出6、stdout为空，新Cookie保留不回滚 |
| Cookie与DTO失败组合 | 2xx+非法目标Cookie+无效DTO | 退出6，先诊断Cookie，不写缓存、不继续DTO校验 |
| 错误业务续签 | 400/500+合法Cookie | 更新缓存后退出6，保持业务错误 |
| 双错误 | 错误业务+续签保存失败 | 主退出码不改，stderr说明两者 |
| 非2xx与非法Cookie组合 | 非2xx主错误+非法Cookie/属性 | 保持HTTP主退出码，安全补诊断，不写缓存 |
| 无效Cookie响应 | 同名多值/非法值 | 退出6，不猜测、不输出成功 |
| 固定host-only | 目标Cookie带Domain，包括相同host/空值 | 2xx退出6，不保存；不能接受为domain Cookie |
| 固定Path | 目标Cookie缺Path或Path不为/ | 2xx退出6、旧缓存保持；Path=/接受 |
| Max-Age规则 | 缺省或2592000；0、负数、其他值 | 前两者接受，其他2xx退出6，不实现删除/任意TTL |
| Expires规则 | 目标Cookie有Expires，即使合法日期 | 2xx退出6、不保存；当前服务固定不发送该属性 |
| 属性与多Cookie | 目标已知属性重复；其他Cookie含Domain/Path | 目标重复退出6，非目标Cookie忽略；属性名大小写不敏感 |
| 其他Cookie | 非awb_session | 不持久化到认证配置 |
| Secure | HTTP登录返回Secure；缓存Secure的HTTP查询 | 登录错误不覆盖；查询不发SecureCookie |
| 重定向 | 任意3xx | 不跟随，退出6，不发送至新地址 |
| 网络边界 | 连接失败、headers后body中断、30秒超时 | 退出5，不缓存部分响应 |
| DTO错误 | 缺字段、负数/浮点计数、total不一致 | 退出6，不打印部分列表 |
| 仅诊断 | 所有错误 | stderr、非0；token/Cookie/请求体不回显 |

## 统一文本与大结果

- 断言字段固定顺序（创建时间在最近更新时间前）、完整ID、UTC时间、标题转义、零匹配及末尾`查询结束：已输出 N 个 Session。`。
- 没有JSON参数，没有自动跳过；正文输出只用固定模板。
- >8,000字符且<200,000字符、未触及512KiB的普通多行输出，通过现有工具artifact继续read；这是预览截断，不要求CLI失败。
- artifact超过200,000字符会丢尾部，验证归档truncated标记，不宣称全部保存。
- bash超过512KiB验证outputLimitExceeded及采集丢失；工具completed不能视为完整成功。
- read的大页面/长行边界按现有机制说明，CLI避免单行大JSON；不改上限，不加分页或outfile以“通过”测试。
- API全量正确与模型最终可见完整是两个验收层次，测试记录必须区分。

## 必须保持的回归

- tabs/continuable原参数、metadata-only读侧、分页和标签可见性不变。
- 现有Web登录、健康检查、401返回、前端重新登录流程不变；仅新增续签响应头。
- 内部token认证保持独立，关闭Web鉴权也不能免内部认证。
- Agent写回、压缩、Fork、定时任务与工具截断规则不因本次查询改变。
- 根build/typecheck/test包含CLI，API现有测试门禁完整。

## 创建时间增量验收

本节追加于首次104个命名案例，不改变既有筛选、排序、计数或鉴权口径；增量执行与审查状态单独记录。

| 案例 | 数据/条件 | 必须结果 |
|---|---|---|
| 创建时间必填与数值 | 缺失、null、字符串、浮点、超Date范围及合法极限 | shared/CLI拒绝非法条目；API损坏元数据500 STATE_INVALID，CLI无效DTO退出6；Date合法上下限接受 |
| Fork创建时间归属 | 来源与Fork有不同created_at | 两者各返回自身时间，不继承来源、不增加关联查询 |
| 创建时间与更新窗口独立 | 创建时间在窗口外、更新时间在窗口内 | 会话仍匹配；不施加创建时间窗口或createdAt与updatedAt比较，排序与累计数不变 |
| 创建时间UTC与字段顺序 | 非UTC终端、全量及零匹配 | 每条输出创建时间UTC ISO，紧邻最近更新时间之前；零匹配不伪造条目 |
| 创建时间版本联动 | 新CLI收到缺createdAt的旧式非空DTO | 退出6、stdout为空，合法续签仍按原优先序保存；API与CLI同步升级，不增加兼容模式 |

## 交付通过标准

- 所有范围内单元/集成矩阵通过，人工安装项有实际证据。
- 对不适用平台或未运行步骤明确标记，不写成通过。
- 没有未说明的契约变化、隐式截断、默认时间、凭证持久化扩张或业务场景语义。
- 审查发现问题全部关闭后，才将本方案对应实现判定为通过。
