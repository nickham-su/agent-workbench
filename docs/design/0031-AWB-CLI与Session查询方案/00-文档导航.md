## 核心结论

- 新增独立 Node.js CLI，使用 TypeScript 薄 HTTP 客户端和分层帮助，固定Node22 CommonJS单文件 `dist/cli.cjs`；只有一套可读文本输出，没有 `--json`。
- CLI 独立登录，缓存现有 Web Cookie 和 API 地址；不依赖 Worker 注入身份或凭证。
- 现有无状态 Cookie 增加阈值续签：普通 24 小时/剩余 6 小时，记住登录及 CLI 30 天/剩余 7 天。
- 新增独立、通用、全量的 Session 查询接口，保留旧 `tabs/continuable` 元数据接口的行为。
- 查询必须显式指定 Workspace 和最近更新时间窗口，窗口正且不超过 90 天，不提供起止时间、分页、游标、数量限制或 `--all`。
- 返回当前 `idle/running` 状态和本会话原生累计 `userMessageCount/completedAssistantMessageCount`，不读正文，不依赖 Analytics。
- Docker 安装程序到镜像固定位置，用户目录只存配置；内置终端和 Worker 默认共享同一用户缓存。

## 范围边界

- `subtask fork` 指定来源能力由另一开发线负责，不作为本方案交付或验收依赖。
- 不改定时任务，不创建自动化任务，不编写日报 prompt，不添加报告、总结副本等业务识别。
- 不加入 Run token、scope/RBAC、凭证数据库、跨进程锁、多 profile、查询快照、期间统计或实时上下文计数。
- 已有工具预览 artifact 不保证任意大小输出完整保存。本次不改工具截断链，不增加文件输出参数。
- Worker 环境继承内部凭证是独立已知问题，记录但不捆绑成本方案前置修复；CLI 不读取或使用内部凭证。
