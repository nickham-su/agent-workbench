## 已确认的范围摘要

- 会话新增不可变的 `visibility: listed | unlisted`；普通 Fork 可显式选择 unlisted，隐藏来源及隐藏执行父的派生会话继承隐藏。
- 普通发现列表、活动查询及 total、recent、全局完成 SSE 导出排除 unlisted；按 ID 读取、执行和明确关联元信息保留。
- 每个真实 Session 持有一条实际 Tab 状态；默认值仅创建时应用。创建、初始化必须原子；后续开闭只更新布尔值。
- Unlisted 可以在普通 Agent Tab 中显式打开、操作、刷新恢复、关闭；不提升为 listed，不另建只读查看器。
- 定时任务的两种创建模式对新声明执行固定使用 unlisted，无用户配置；旧执行继续按原语义恢复，历史锚点不变。
- Unlisted 父任务不能复用既有 listed 子会话；覆盖已有 child Run 与竞争 winner 复用捷径。
- v23 到 v24 采用独立非破坏性迁移，保留历史及原 Tab 开闭结果，不进入历史重建流程。

## 明确不包含

- 会话 owner／ACL、调用者独占访问或“所有响应永不包含隐藏 ID”的保证。
- TTL、自动删除、会话清理平台、工作区／Git／文件隔离。
- 可见性改回 listed 的入口、隐藏会话管理页、专用通知体系。
- 定时任务的可见性配置开关、`outputVisibility` 配置列、最新消息 Fork 策略。
- 为本功能建立通用迁移框架、改写生命周期恢复或弱化内部鉴权。
