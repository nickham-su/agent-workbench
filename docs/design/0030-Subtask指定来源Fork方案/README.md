## 当前规则摘要

- 扩展现有 `session.mode=fork`，仅新增可选请求参数 `session.sourceSessionId`，不新增 mode，也不向模型开放消息锚点参数。
- 不传来源，保留原 caller Fork、prefork、工具锚点和空历史行为；传来源，从同 Workspace 的 primary/subtask 当前分支选取最新稳定有效上下文。source 可以等于 caller，但显式路径不使用 caller prefork。
- 稳定解析仍在第一个进行中消息或未闭合工具所属 Assistant 之前截断，不跨越、不拆分；压缩 root/retained、System/Compaction 内部锚点及既有图防护保留。
- **对外响应仅增加 `AgentApiSubtaskStartResponse` 顶层 `sourceSessionId?: string`**，仅显式首次成功和复用成功返回。原有五个字段不变，旧模式不增加来源字段。
- **内部实际消息边界仍写入 Session 的 `forked_from_message_id/head/root`**，用于共享历史和安全补偿；不输出该边界，也不记录排除布尔。
- 首次、同父工具重试和并发 winner 的新增来源语义，以不可变父 tool-call input 为权威；只比较来源是否显式及规范 ID，不增加完整调用指纹，不用于历史回放。
- 同一父工具内部重试复用同一 Child 和原有 Session 锚点，不重新查询实时 source。另一工具调用是新副本，重新捕获当时稳定上下文，没有公共指定历史快照参数。
- Worker running/final 结果可携带同名可选来源字段，并在既有成功/错误投影中简短展示。历史结果按原有 preview/error 机制回放，**不保证每条 unknown/cancelled 结果均有来源说明**；可选说明缺失或非法不阻塞回放，不猜测补来源。
- 不新增来源专属工具结果保留规则、跨实体来源回放校验或 DB schema；messages/tools 闭合、可信附件及现有共享图/归档保护不变。
- 新副本 `lastResponseTotalTokens` 初始为 null，首次请求没有自动压缩兜底保证；应选窗口足够的总结 Agent，实际超限按旧失败语义处理，不新增预估摘要。

## 术语与约束

| 术语 | 定义 |
|---|---|
| 调用者 / 执行父任务 | 发起工具调用的 Session / Run，负责父执行关系、结果接收与取消级联 |
| 来源 Session | 提供共享历史的 Session，可不同于调用者 |
| 隐式 Fork | 未提供来源字段，完全沿用原 caller 路径 |
| 显式来源 Fork | 提供有效来源字段，走本方案稳定来源入口 |
| 有效模型上下文 | 当前 root、压缩摘要、必要 retained 与后续有效内容，不是全部物理历史 |
| 内部实际边界 | 服务端选取的 `sourceMessageId`，只用于内部 Session 分支记录，不属于请求或响应 |
| 隔离 | Session 消息追加、Run 状态及执行归属独立；不复制文件、终端或远端环境 |

- Session 来源关系与 Child Run 执行父关系分离；Agent/profile/model 按请求解析，不复制来源身份、权限或 override。
- 来源不存在与异 Workspace 使用同一安全错误。首次分支选/验/创建在同一 immediate 事务完成，Child 激活仍沿用既有父 fence。
- start 路由 schema 前进行新增字段原始验证，保留 prefork 存在性错误优先级，不改全局 AJV、不收紧无 source 旧请求。
- 安全 cleanup 不要求 source 等于 caller，但仍保护共享历史及已有工作；公共手动 Fork、定时历史 Fork 不放宽。
- 正式 API 验收必须包含完整 test gate；API/Worker 同版本发布，入口阻断、计划暂停和真实收敛步骤见实施文档。
