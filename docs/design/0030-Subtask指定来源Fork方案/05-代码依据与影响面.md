## 首次上下文窗口限制依据

- agent-message.store / 分支创建：新 session_run_state 不复制来源 token 统计，新副本 lastResponseTotalTokens 初始 null。
- runner / shouldAutoCompact：取上次 lastResponseTotalTokens，null 直接返回 false；模型步骤前调用此判断不是首请求 token 预估。
- 因此大来源配小子模型不保证首请求自动压缩。推荐足够窗口 Agent，实际超限走旧失败语义；本次不新增预估摘要或 runner 压缩算法改造。
