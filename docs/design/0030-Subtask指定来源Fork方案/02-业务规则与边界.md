## 调用参数

| 输入 | 规范行为 |
|---|---|
| new / existing | 保持现有空上下文 / 继续执行行为及目标限制 |
| fork，不含 sourceSessionId | 保持原隐式 Fork，不切换到新增稳定来源算法 |
| fork，含有效 sourceSessionId | 对指定来源执行新增稳定分支流程 |
| new/existing 出现 source 字段 | 拒绝，包括空值或 null，不允许静默删除 |
| fork source 类型非法或 trim 后为空 | 拒绝，不转换、不退回 caller Fork |
| 模型指定 sourceMessageId、等待策略等 | 不开放这些参数；不能借额外字段获得历史锚点权限 |

- 新字段必须在工具 schema、Worker、API start 路由 schema 前原始验证及应用直调一致处理，不能等 AJV 转换/删字段后再检查。
- 显式来源请求出现 `preforkSummaryText` 或 `preforkMeta` 即拒绝，包括空/null；显式 Worker 不生成这些字段，不调用 caller prefork plan/messages-context/摘要。
- 既有 sessionId 的形状与应用层拒绝策略不变，不把它当 source 别名，不收紧其他旧字段。

### 唯一新增字段错误优先级

- HTTP 解码和既有认证等基础拒绝先行；新增 hook 不绕过认证，无 source 请求仍走旧校验。
- 原始 session 有 source 但 mode 非法：既有 SESSION_MODE_INVALID，不允许类型转换成合法 mode。
- mode=new/existing 且 source 存在：SOURCE_SESSION_NOT_ALLOWED，先于 source 类型及 prefork 错误。
- mode=fork 且 source 存在：原始值必须是字符串且 trim 后非空，否则 SOURCE_SESSION_INVALID；数字、布尔、数组、对象、null 均拒绝。
- source 合法后出现任一 prefork 字段：PREFORK_NOT_ALLOWED，先于 prefork 自身类型/长度错误。
- 然后进入既有 schema/基础参数、可信父锚点、持久 input 来源绑定、Child 复用或新来源解析。不能在新增检查前全请求 Value.Check。
- 仅 start 路由使用 preValidation，不改全局 AJV；纯新增字段校验可供 Worker/应用复用，不成为通用 strict 框架。

### 调用时来源语义绑定

- 不可变父 tool-call Part 的持久 input 是首次“source 是否存在及规范 ID”的权威，start 请求只是传输。
- 首次、同父工具重试、并发 winner 都先比较新增来源语义；显式/隐式切换、source ID 改变均为 MISMATCH，不先查实时来源。
- 持久 JSON 缺失、坏 JSON、非对象或持久 source 的类型/值/模式非法为既有 ANCHOR_INVALID，不默认隐式、不猜请求。
- 合法旧 input 无 source 字段仍兼容，不新增完整 mode/agent/prompt 指纹；原有父权限、Agent、深度等校验继续。
- 已有显式 Child 的来源从其 Session.forked_from_session_id 取得，按调用时一致性需要与绑定 ID 核对；不依赖工具结果中的来源说明。该来源关系与绑定 ID 不符为 MISMATCH。
- source=caller 不能单凭 Session 来源字段区分隐式/显式；只能由合法绑定 input 决定是否返回来源字段。
- 以上校验只在调用阶段执行，不搬进历史 Resolver/transcript。

## 来源可访问范围与复用

- 新材料化只允许当前父锚点 Workspace 的 primary/subtask；不存在与异 Workspace 同一安全错误，不泄漏来源细节。
- source 可以是 caller，仍走显式入口；可以是已 Fork 的 Session，允许继承其当前链共享祖先，不限制 origin_session_id 必须等于 source。
- 新调用只取来源当前分支；已回滚内容不能进入新副本，不借用定时历史 Fork 的宽权限。
- 不要求 source idle，不改 source 状态、不向 source 排队或取消。
- 同一父工具内部重试复用同一 Child、已有 fork 锚点和 root，不重新挑边界；来源之后前进/回滚/不可查询不额外阻断复用，仍校验既有父权限和调用一致性。
- 模型另一工具调用创建新副本，重新捕获当时稳定上下文；没有公共指定历史快照参数，不暴露消息边界不影响服务端幂等。
- 并发 loser 必须重新执行绑定 input 与 winner Session 来源一致性检查，才可复用；只安全补偿自己本次未激活的空副本。

## 稳定边界规则

### 连续前缀

- 在同一 immediate 事务内读取当前 source head/root、必要消息/Parts/ToolExecution，校验、选边界、创建副本。
- 保留当前有效模型上下文的连续可回放前缀，不是选“最后一条 completed 消息”。
- 前缀包含合法有效根；压缩摘要和必要 retained 整体闭合，不能删必要尾部掩盖损坏。
- 在第一个进行中消息或带未完成工具的 Assistant 之前停止，整条 Assistant 及其已完成的部分工具均排除，不跨越它纳入后续 completed 内容。
- 已完成 User 且之前闭合时可作为边界；本次 prompt 决定副本任务，不继续源任务。
- 内部 sourceMessageId 必须保存为实际 Session 分支锚点；不输出边界，不保存排除布尔。模型统一知晓仅继承稳定有效上下文，不保证进行中内容。

### 状态处理

| 对象状态 | 稳定解析行为 |
|---|---|
| completed User/System，合法 Parts | 可纳入并作为内部边界 |
| completed Assistant，无工具或全部工具 completed | 可纳入，工具调用/结果成对且有序 |
| completed Assistant，工具 failed/cancelled/unknown | 终态按既有错误/取消/unknown 表示纳入，不宣称成功 |
| completed Assistant，任一工具 queued/running | 整条 Assistant 及后续内容截断，不拆分 |
| streaming 普通消息 | 在该消息之前停止，不纳入半条文本；当前消息契约无 pending 状态 |
| failed/cancelled/superseded Message | 按既有模型规则不回放、不作为边界，不把它变成 completed |
| runtime 消息 | 按旧规则不纳入，不能当有效边界 |
| completed Compaction | 尊重摘要与 retained，可作为内部边界；边界为 compaction 时 root=self |
| 工具记录缺失/重复/状态非法/归属不符 | CONTEXT_INVALID，不视为正常 pending、不伪造工具结果 |
| root/retained/Parts/Provider replay 损坏 | CONTEXT_INVALID，不静默丢必要历史；既有可兼容的旧 replay 降级保留 |

- 不以 messageTerminal() 替代模型可回放判定；其终态集合包含不回放的 Message。
- 压缩前且非 retained 的内容不自动进入新模型窗口，但物理当前链仍检查缺失、循环、跨 Workspace 和既有图防护上限。
- 原始候选必须保留 streaming/工具进行中的截断点，不能先 normalized 过滤再找稳定边界。
- 必要 retained 原始区间必须整体闭合，即使某些终态 Message 本来会被模型排除，也不能借过滤跳过残留 pending 工具。

### 根与必要 retained 错误矩阵

| 位置与状态 | 唯一行为 |
|---|---|
| 普通 root streaming 或 completed Assistant root 仍有 queued/running，且无合法前缀 | NO_STABLE_CONTEXT，不转旧 root、不拆消息 |
| 显式普通 root 为 failed/cancelled/superseded/runtime 或结构损坏 | CONTEXT_INVALID |
| compaction root 未 completed 或摘要/指针/结构非法 | CONTEXT_INVALID |
| completed compaction 的必要 retained streaming/未闭合工具/非法关系 | CONTEXT_INVALID，不过滤、不删尾部、不回退旧 root |
| 合法根后进行中候选，有合法稳定前缀 | 成功并在内部前一稳定消息截断，不返回排除事实 |
| 无 root、空历史或仅不可回放历史，无合法稳定内容 | NO_STABLE_CONTEXT，与设置非法 root 区分 |

## 隔离、窗口与结果

- 新 kind=subtask Session 有独立 head/revision/run state；共享稳定历史，不复制 active Run、pending 工具、重试/流式状态。
- 源之后追加、压缩、回滚不会移动副本已存边界或 root。共享图/归档保护继续，不另存父/Child来源证明链用于回放。
- Child parent_run_id/parent_tool_execution_id/depth 来自 caller。Agent/profile/model 按请求，不复制源身份、权限、基础配置或 model override。
- 同 Workspace 文件、终端、插件和远端资源不复制；需要只读总结时用实际工具配置限制，非本次权限 UI/沙箱目标。
- 新副本 lastResponseTotalTokens 初始 null，runner.shouldAutoCompact 基于上次 token 数，此时 false；首次请求超子模型窗口没有自动压缩兜底，应选窗口足够的总结 Agent，超限按旧失败语义处理，不新增预估摘要。
- start 顶层仅新增 sourceSessionId?: string，显式首次/复用成功返回；sessionId/runId/workspacePath/agentName/reused 不变，旧模式不增加来源字段。
- Worker running/final structuredResult 可携带同名字段，在既有成功/错误投影中简短展示；成功 start 后已有来源可随旧 error carrier 呈现，未成功 start 不伪造成功来源。
- 普通结果仍用 structuredResult 和 preview/error；不为 source 新增服务器保留键、合并/防篡改或终态写回规则。
- 历史按旧机制回放，不读实时 source head/状态，不关联 Child/input/fork 字段来验证来源，不保证直接 unknown/cancelled 结果有来源头。
- 如简单展示读取可选来源，只做类型/格式检查，非法省略、不猜补；可选来源缺失/损坏不能让历史回放失败。messages/tools 闭合、可信附件等既有防护不变。

## 生命周期与安全补偿

- 父取消按执行链取消 Child，不取消无执行父关系的来源；source 仅自行取消/结束不导致 Child 取消。source=caller 时仍按父关系取消。
- 未激活副本满足全部空闲/无自有工作条件才能补偿；精确匹配本次 ID、来源和内部边界，不要求 source=caller。
- 不删共享历史、来源、existing 目标或已有 Run/自有消息/工具/后代/override 的副本；激活后失败保留会话和旧失败结果。
- 材料化后激活前崩溃空壳继续走原有保守孤儿策略，不扩大共享图清理。

## 对外错误语义

| HTTP / 代码 | 条件与约束 |
|---|---|
| 400 AGENT_SUBTASK_SOURCE_SESSION_NOT_ALLOWED | new/existing 出现 source 字段 |
| 400 AGENT_SUBTASK_SOURCE_SESSION_INVALID | fork source 原始类型或值非法 |
| 404 AGENT_SUBTASK_FORK_SOURCE_UNAVAILABLE | 新材料化来源不存在/异 Workspace，同安全消息 |
| 409 AGENT_SUBTASK_FORK_SOURCE_NO_STABLE_CONTEXT | 新材料化无合法稳定前缀，不等待、不退 new |
| 409 AGENT_SUBTASK_FORK_SOURCE_CONTEXT_INVALID | 新材料化图/必要有效内容损坏，固定安全诊断 |
| 409 AGENT_SUBTASK_FORK_SOURCE_MISMATCH | 调用来源语义与持久 input 不符，或已有 Child Session 来源关系不符 |
| 400 既有 AGENT_SUBTASK_PREFORK_NOT_ALLOWED | 显式请求出现任一 prefork 字段 |
| 既有 AGENT_SUBTASK_ANCHOR_INVALID | 持久父 input 缺失/坏 JSON/非法来源；其 HTTP 映射保持 |

- SQLite busy 按基础设施旧通路，不冒充 NO_STABLE。其他 parent/agent/depth/existing/prompt 错误保持。
- 不新增来源说明缺失类错误；可选展示损坏与调用锚点损坏是不同问题。诊断不打印 prompt/reasoning/工具输出或凭据。
