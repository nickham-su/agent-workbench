## 验收原则

- 下列验收要求及 97 行矩阵保持不变。指定来源 Fork 本地实现、阶段一至五独立代码审查和最终独立全面审查及复审通过；完整正式 Shared/API/Worker gate 2034 项通过；生产发布未执行。 L2 已修复并复审 Resolved；L1 为已接受本次 WontFix 的 Open 既有非阻断维护项。矩阵对应的真实测试/替身/静态证据及最终独立验证边界见 [09](09-实施与验收记录.md)；真实生产演练未执行，不以本地测试替代。
- 每项给出明确断言；对外单字段、内部边界、调用一致性、取消/补偿和旧回放兼容分别验证。
- mock 可验证分派/Provider，但图/事务/unique constraint/cleanup 需真实 SQLite 证据；不新增来源专用持久化或严格关联回放矩阵。
- UNAVAILABLE/NO_STABLE/CONTEXT_INVALID/MISMATCH 为 02 的相应来源错误简称，ANCHOR_INVALID 沿用旧错误。
- 示例 U/A/B 表示实际消息链，pending-tools 指工具 queued/running，不创建不存在的 pending Message 状态。

## 旧模式与参数兼容

| 场景 | 验收预期 | 验证层 |
|---|---|---|
| new | 原空背景、原响应/工具结果，无新增来源字段 | API/Worker |
| existing idle subtask | 继续指定会话，原输出；primary/运行中/异 Workspace 继续拒绝 | API/SQLite |
| implicit fork | 仍用 caller 工具 Assistant previous 锚点，不纳入当前工具调用，不走稳定来源新入口 | 应用/集成 |
| implicit fork 空边界 | 仍旧空会话回退，不改为 NO_STABLE | 应用 |
| implicit prefork 阈值命中/摘要失败 | caller 单次摘要、顺序及安全回退不变，旧模式不增来源字段 | Worker/集成 |
| nested implicit fork | 原父工具链/depth/guard 保持 | 集成 |
| fork source 合法字符串或首尾空白 | Worker 重建后保留规范 ID，API 接收/输出同规范 ID | Shared/路由/Worker |
| source null/数字/布尔/数组/object/空白 | SOURCE_SESSION_INVALID，不强转/退隐式，不创建副本 | Worker/HTTP |
| new/existing 出现 source | SOURCE_SESSION_NOT_ALLOWED，含空/null，不删字段后接受 | HTTP/应用 |
| 把 sessionId 当 source | 维持旧合法/拒绝规则，不变来源别名 | Worker/API |
| explicit 带任一 prefork 字段 | PREFORK_NOT_ALLOWED，无 caller 摘要与源创建 | API |
| explicit 且 caller 上下文大、source=caller | caller prefork plan/messages-context/摘要调用次数均零 | Worker |
| 模型附 sourceMessageId 或等待策略 | schema 不开放，不能取得指定历史边界权限 | 工具 schema |

### 原始 HTTP 错误优先级

| 原始请求 | 验收预期 |
|---|---|
| 有 source 但 mode 非法/可被转换 | SESSION_MODE_INVALID，不转换 mode |
| new/existing source 任意值并带坏 prefork | SOURCE_SESSION_NOT_ALLOWED 优先 |
| fork source 非字符串/空白并带任意 prefork | SOURCE_SESSION_INVALID 优先，含数组转标量风险 |
| fork source 合法，prefork 空/null/数字/数组/object/合法值 | 每种均 PREFORK_NOT_ALLOWED，先于 prefork schema 类型/长度错误 |
| source 数字转换后恰好对应实际来源 | 仍 SOURCE_SESSION_INVALID，不创建副本 |
| 新增请求未认证 | 既有认证拒绝，无来源信息/材料化副作用 |
| 无 source 的旧合法/非法请求 | hook 不新增全量 strict 校验，原认证/schema/handler 行为不变 |

- 以上必须使用真实 createApp/route 默认 AJV 的 Fastify inject；纯 Value.Check/应用直调不能替代，Worker/应用仍验证同顺序。

## 来源范围与内部稳定边界

| 场景 | 验收预期 |
|---|---|
| 同 Workspace idle/running primary 或 subtask | 新 kind=subtask，内部来源/边界正确，不向源追加任务 |
| source=caller 显式 | 新入口选稳定前缀，正在等待本工具的 Assistant 不纳入；input 决定显式返回 |
| 来源不存在/异 Workspace | 同 UNAVAILABLE/HTTP/固定安全消息，不泄漏标题/类型/状态，无新副本 |
| 来源已有 Fork 共享祖先 | 按当前链继承，不以 originSessionId 必须等于来源过滤 |
| 来源回滚后新工具调用 | 只取回滚后分支，旧回滚内容不成为边界 |
| 仅 completed User 或新增 completed User 且之前闭合 | 可为实际内部边界，本次 prompt 决定任务 |
| 空源/无 root 且仅不可回放历史/首条 streaming 无前缀 | NO_STABLE，不退 new，不留新 Session |
| 材料化成功 | forked_from_session_id=source，forked_from_message_id=实际 sourceMessageId，创建 head=边界，root=有效根；无对外边界/排除字段 |

### 连续前缀、消息/工具闭合

| 场景 | 验收预期 |
|---|---|
| 源 running 而有效内容全稳定 | 可成功，不用 source status 替代稳定判定 |
| U → streaming A | 边界 U，A 文本/reasoning/tool_call 全排除 |
| U → completed A、工具 queued/running | 边界 U，整条 A 排除，包括其已 completed 的另一工具 |
| U → pending-tools A → completed B | 仍在 A 前停止，不跨越 B |
| A 无工具或全部工具 completed | 可纳入，Part.position 顺序和调用/结果配对正确 |
| A 工具 failed/cancelled/unknown | 终态错误/取消/unknown 正常闭合，不重执行、不说成功 |
| failed/cancelled/superseded Message 或 runtime | 保持旧排除，不当边界，不与终态工具混淆 |
| idle 来源有效尾部有未闭合工具 | 可在此前前缀截断，不因 idle 绕过闭合 |
| 工具缺失/重复/非法状态/归属不符或有效 Parts 损坏 | CONTEXT_INVALID，不伪造、不当正常 pending |
| 稳定边界前有效祖先工具损坏 | CONTEXT_INVALID，即使最后消息 completed |
| 合法旧 Chat v1 无 endpoint replay | 保留现有兼容降级，不收紧历史 |
| 进行中 A 的 Parts 后续继续更新 | 副本不含 A，源后续变化不进入副本 |

### root、retained 与图防护

| 场景 | 验收预期 |
|---|---|
| compaction + retained + 后续稳定内容 | 摘要/retained/后续顺序一致，必要区间完整 |
| head 恰为合法 completed compaction | 边界=compaction，root=self，retained 不丢，不退旧窗口 |
| compaction 后仅 streaming | 边界 compaction，不把 retained 末尾当新 head |
| 合法普通 System/User root | 尊重有效范围，可作新增内部边界 |
| 普通 root streaming 或工具 pending，无合法前缀 | NO_STABLE，不回到 root 前物理祖先 |
| 设置普通 root 为不回放终态/runtime 或结构损坏 | CONTEXT_INVALID，与未设置 root 的无稳定历史区分 |
| compaction root 未 completed/摘要坏/指针坏 | CONTEXT_INVALID，不作普通截断 |
| 必要 retained streaming、queued/running 工具 | CONTEXT_INVALID，不 normalized 过滤、不删 retained、不退旧 root |
| 必要 retained 中排除终态 Message 残留 pending 工具 | CONTEXT_INVALID，先检查原始必要区间，不借过滤绕过 |
| root 不在链/缺失；retained 越界/缺失/跨 Workspace | CONTEXT_INVALID，无副本 |
| 物理链循环/缺失/跨 Workspace/超过上限 | 有限时间 CONTEXT_INVALID，不绕过图防护 |
| 压缩前非 retained 历史 | 不进新模型窗口，既有 Archive/共享图保护继续 |
| 公共手动/定时历史 Fork | 原 user/assistant 锚点、源 fence、primary/授权规则不放宽 |

## 事务、内部重试与调用一致性

| 场景 | 验收预期 |
|---|---|
| WAL 两连接源追加/压缩/回滚与材料化竞争 | 同 immediate 事务的自洽 source/root/tool 视图，不混合新旧 |
| 源连续流式 revision 变化 | 无事务外旧 revision 循环冲突；busy 走旧基础设施错误 |
| 分支后源追加/工具完成/压缩/回滚 | 内部 forked_from_message_id 与已选 root 不动；副本自身追加只改自身 |
| 同源不同父工具/模型新调用 | 独立 Session/Child，按各次当时稳定上下文捕获，无公共历史快照参数 |
| 同父工具内部同源重试 | 同 sessionId/runId，reused=true，已有内部锚点不重新选择 |
| 同父并发材料化边界不同 | 最多一成功 Child，loser 只清自己的空副本，匹配后返回 winner |
| 已有 Child 后来源前进/回滚/不可查 | 合法复用返回原 Child 与来源 ID，不额外查实时 source 或重新验其当前边界 |
| 持久 input 显式 A，传输 A 含首尾空白 | 规范化一致，首次/重试/winner 可匹配 |
| 持久 input 隐式但请求加 source，或显式 A 请求丢 source/改 B | 首次/重试/winner MISMATCH，不创建第二成功 Child |
| 旧 Worker 丢 source 又带 caller prefork | 锚点后 MISMATCH，不走 caller boundary/meta；部署仍不支持混跑 |
| 持久 JSON 缺失/坏/null/数组，或持久 source 非法 | ANCHOR_INVALID，不默认旧隐式、不按传输补 input |
| 合法旧 input 无 source | 原调用兼容，不增加完整 mode/agent/prompt 指纹 |
| source=caller 的显式与旧隐式 Child | 仅合法 input 决定是否显式，不能从 forked_from=caller 猜 |
| 显式 input 与 Child Session.forked_from_session_id 不符 | MISMATCH，不依赖工具结果来源说明作权威 |
| 同父 winner/loser 复用 | loser 再读 input/目标 Session 核对，不无条件 catch 复用 |
| tool-call 流式重复修改 input | 现有写入口拒绝，持久 input 不变，不新增写回规则 |

## 生命周期、安全补偿与 profile

| 场景 | 验收预期 |
|---|---|
| source≠caller | Session 来源指 source，Run parent/depth 指 caller |
| 父锚点无效/深度超限/Agent 禁用/Workspace 删除 fence | 继续既有拒绝，新 source 不绕过 |
| 材料化后、激活前 parent/profile/prompt 失败或取消 | 旧失败语义，精确安全清理本次空副本，不改源 |
| 激活后父取消 | 按执行父链取消 Child，独立来源不被取消 |
| source 自行取消/结束且非 caller | 不按来源取消 Child；source=caller 仍执行父取消 |
| source≠caller 的空副本共享 head | 可满足补偿条件，源 Message/Part/工具保持原值，不删除共享图 |
| 副本已有 Run/自有消息/工具/后代/override 等 | cleanup 被保护，不视为空壳 |
| existing 失败或已激活 Child 执行失败 | 保留会话/原历史/旧失败结果，不做创建失败删除 |
| 创建后激活前崩溃 | 原保守孤儿策略，不能删共享图或制造第二成功 Child |
| 请求 Agent 与来源不同，来源有 override | 使用请求 profile，不复制来源身份/权限/override |
| 新副本 token 统计 | lastResponseTotalTokens=null，shouldAutoCompact=false，不继承来源统计 |
| 首次上下文超子模型窗口 | 不承诺自动压缩；不调用 caller prefork/新预估摘要，Provider 失败按旧语义 |
| 历史图片/私有 replay/失效附件 | 既有适配、可信附件/错误规则保留，不承诺全量视觉或瞬时记忆 |
| 副本有写工具 | 外部文件不隔离、不隐式改权限，文案不误承诺只读 |

## 单字段输出与原有历史回放

| 场景 | 验收预期 | 验证层 |
|---|---|---|
| 显式首次成功/复用成功 start | 顶层规范 sourceSessionId，五旧字段不变；复用取已核对 Child Session，不带边界/排除/包装字段 | Shared/HTTP/应用 |
| 旧 new/implicit/existing 输出 | 无新增来源字段，无 null 占位或来源头 | Worker/HTTP |
| 正常 Worker running/final | 可携带同名普通字段，旧结果字段/写回机制不变，成功短展示来源 | Worker/runner |
| 成功 start 后错误且有来源 | 已有 error carrier 可传 ID，旧错误投影简短显示，不说总结成功 | Worker/error capture |
| start 未成功或来源说明不可用 | 不伪造成功来源，原错误结果继续 | Worker/API |
| Worker 未首写，服务器直接 unknown/cancelled，无 preview/error | 允许没有来源说明；旧 status 投影正常，不让整段历史失败 | store/Resolver/transcript 回归 |
| failed/cancelled 的 error 优先于 preview | 旧 error 优先保持，不要求额外强制来源头 | transcript 回归 |
| 可选 source 缺失/null/数字/object/坏格式 | 原历史继续；如有简单展示读取，非法省略，不猜补 | Worker/历史兼容 |
| 工具结果 source 与其他实体不一致 | 展示字段不变成证明链校验，不影响历史；实际 start 调用一致性仍独立验证 | 历史/调用对照 |
| 历史来源已前进/回滚/不可查 | 不读实时 source head/状态，不为来源关联 Child/input/fork 字段 | 回放回归 |
| 普通 structuredResult 更新/终态一致重放 | 旧替换/一致性行为保持，无来源专属保留/合并/防篡改规则 | store 回归 |
| messages/tools 不闭合或可信 imageRef 归属不合法 | 原有底层防护继续拒绝，不能借“可选来源”放宽 | Resolver/transcript 安全回归 |
| 来源文本含引号/控制字符 | 短展示安全编码，不从正文解析权威 ID，不增加规范块/去重任务 | runner |
| 诊断日志 | 无 prompt/reasoning/完整输出/token，跨 Workspace 不泄漏 | 安全审查 |

## 正式 gate 与发布门槛

- Shared/API/Worker 的正式类型检查/测试通过；正式 API 为 npm test -w apps/api 或 npm run test:all -w apps/api，含 verify-test-gate 和三个分类。定点/分类/Value.Check 不替代完整验收。
- 没有 DB 表/列/版本变化或 destructive rebuild；没有公共/定时 Fork、活跃查询、权限 UI 的无关扩展。
- API/shared/所有 Worker 同版本，旧 Worker 不接新 source 工具输入；不能把丢字段当降级支持。
- 发布演练覆盖根消息、手动 compact、插件/CLI/internal trigger、定时 run/enable/create/replace、外部 enqueue 阻断，计划 pause 不忽略已 claim execution，在途内部子任务/写回/压缩/终态继续。
- 持久 Run/Session/queued-running 工具/计划 execution 与所有 Worker 新鲜 queueLength/activeCount、fallback 证据完整，两次观测真实收敛。无法隔离/观测或超时即中止或经授权受控取消，不伪造全局 drain。
- 版本制品验证、只恢复原启用计划与入口、回滚前显式 pending input 收敛均保留；有新版显式 pending 输入禁止降级 Worker。

## 独立审查重点

- 外部是否确实只增一个顶层可选 ID，内部消息锚点和闭合规则是否完整保留？
- raw hook、认证、错误优先级、无 source 旧请求是否有真实 HTTP 证据？
- input 是否不可变，首次/重试/winner 是否只绑定新增来源语义，source=caller 是否不猜字段？
- 首次材料化是否同事务且保留第一个进行中截断，必要 retained 是否未过滤/删减？
- 同父工具是否复用原锚点而不查实时 source，新工具是否重新捕获，loser 是否一致且安全补偿？
- 是否已删来源证明链/强制来源回放依赖，而原 messages/tools/可信附件/共享图防护保持？
- 可选说明缺失是否不阻塞历史，普通写回/error 优先是否保持，是否没有未知终态必有头的承诺？
- 首次 null token 的窗口风险、Agent 不继承与外部文件不隔离是否准确？
- 正式 gate、同版本部署、所有根入口/计划与真实收敛证据是否完整，是否保留用户无关变更？
