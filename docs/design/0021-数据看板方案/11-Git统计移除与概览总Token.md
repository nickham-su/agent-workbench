# Git 统计移除与概览总 Token（现行修订）

## 决策与适用范围

- 本文是本目录原数据看板方案的**现行修订**：同一次交付移除本次 Dashboard / Analytics 开发引入的 Git 统计，并以模型「总 Token」替换概览「Git 提交」。与旧方案冲突的内容以本文为准；原文保留作为历史设计记录，而非仍待实现的 Git Analytics 需求。
- 仅移除 Analytics 中的 Git 分区、概览 Git 卡片及趋势、180 天热图、Git 数据域状态、Git 扫描与查询、相关共享契约和统计专属持久数据。概览维持六张卡；Agent、Model、Worker 等其他统计继续可用。
- **不移除**既有 Git 仓库登记、克隆/同步、远端凭证、全局 Git 身份配置、提交、Diff / 变更审查和 Workspace Git 操作；不删除业务数据库中的仓库记录或仓库镜像。
- 内部可以按存储与后端、界面与文档分别开发和审查，但它们是**同一次发布**；后端契约与前端不可单独部署。

## 展示与指标口径

- 概览第六张卡显示所选范围内工作台已采集模型调用的跨模型「总 Token」，点击后显示相同范围与时区规则下的按桶总 Token 趋势。模型页现有输入/输出 Token 趋势和其他业务口径不变。
- 沿用模型调用 `total_tokens` 的现有上报或可信推导口径；不再额外加上 cache-read Token，也不能简单将输入与输出趋势相加。卡片与每个时间桶分别依据有效用量样本计算。
- 只有范围或桶内的所有已记录模型调用都具备有效总 Token 用量，才展示完整合计；用量不齐时返回 `null` 并显示 `—`，不把已知部分冒充总量，也不把缺失当作零。模型域覆盖可认证且无调用时显示真实 `0`；覆盖不可认证时不得把空桶认定为零。范围外的平台调用不计入本指标。保留模型域原有的可用性/部分可用/不可用状态语义。
- 「监控数据量」仍为**采集的规范 Fact 条数**，不是 Token 数。定义版本更新为 `dashboard_collected_fact_v2`，只包含 `run / session / message / tool / execution / model / worker` 七个域；旧 Git Fact 和小时缓存均不参与展示。仅调整移除 Git 所必需的构成和历史数据，不改变其他域 Fact 的计数口径。
- 移除前端 Git 专用状态、文案和图表；共享 Dashboard 契约与实际响应不再要求 Git 专用域、指标、趋势或热图。保留原有仓库管理相关 API 和契约。

## 存储迁移与安全边界

- Analytics schema 从 v18 升至 v19；新安装直接采用现行结构，已有受支持旧版逐版升级。迁移在 SQLite 事务中清理四张 Git Analytics 专属表及索引，重建含 Git 约束的小时采集量与域状态表并保留非 Git 行，删除 Git 的 Dirty / Rollup / coverage gap 等缓存或状态行。
- 旧配置版本中的 Git 域需要兼容处理，同时保留其他域的历史配置、时间与标识；不能通过删除或重建整座 Analytics 数据库升级，更不能碰业务库或 Git 仓库/凭证。历史迁移需要的旧版 Git DDL 可以作为升级代码保留，不代表 Git 采集仍在运行。
- 数据库迁移和现行 schema 校验成功后，仅通过受控目录接口按固定文件名幂等删除 Git Analytics 专用的 installation secret；不要把这一清理扩展到普通 Git 身份、远端凭证或其他文件。文件删除不属于 SQLite 事务，失败时应可安全重试，不能误报已完成。
- **已有 Git Analytics 历史数据将不可恢复。部署前应备份 Analytics 数据库**；备份与恢复不得通过清空其他统计或业务数据来替代。部署升级时同步发布前后端和共享契约。

## 实施与验收

- 后端与共享契约：停止 Git Analytics 调度/采集/查询/维护，删除运行时 Git 契约；概览改用模型总 Token 口径和匹配的分桶趋势，监控数据量改为七域及新定义版本；实现并验证安全迁移。不得以移除统计为由更改仓库业务行为。
- 界面与文档：移除看板 Git 分区与专用组件，六卡最后一项改总 Token，切换卡片时能看到同口径趋势；更新中英文文案及响应夹具。模型页、其他统计分区和既有仓库管理界面保持可用。
- 升级测试：v18 有 Git 数据的旧库和更早受支持版本均能迁至现行 schema；新安装可启动；故障注入后迁移回滚、重试成功。核查 Git 表/旧缓存消失，非 Git 事实、汇总、域状态和配置历史保留，旧持久配置不阻止启动，统计专用密钥仅在迁移成功后按固定文件名清理。
- 口径测试：全有用量、部分/全部用量未知、可信真零、有调用但用量未知、无调用空桶、覆盖不完整、范围边界和夏令时分桶分别正确；监控数据量不再含 Git。前端验证无 Git Analytics 导航/热图，点击新卡展示趋势及 `—`/`0` 区别。
- 质量验收：共享包构建、API 与 Web 类型检查、相关单测/集成测试及构建通过；独立审查对照本文核查范围、迁移安全和可维护性。不得修改 `docs/design/0027-workspace-context-discovery-and-enablement/`。
