# 指标口径

本文件是 Dashboard 数值、受控状态与原因码的唯一权威定义。前端、API、SQL、聚合任务不得自行创造替代口径或自由字符串。

## 受控枚举与原因码总表

### 同步要求

| 类别 | SQLite 主库 | Shared TypeBox / TypeScript | Worker 私有 Outbox | 内部 DTO |
| --- | --- | --- | --- | --- |
| 对外指标状态、查询参数、公开错误 | 必须 `check` | 必须 | 如随 delivery 携带则必须 | 必须 |
| Agent/Analytics 内部生命周期 | 必须 `check` | 内部 TS union；若跨进程传输则导出 internal contract | 如随 delivery 携带则必须 | 必须 |
| Worker Outbox 专属状态 | 不适用 | Worker 内部 union | 必须 `check` | 不对外 |
| 安全诊断/失败原因码 | 相关表 `check` 或受控 code 表 | 内部 union；对外仅暴露白名单 | 如写入 delivery 必须 `check` | 必须 |

- 表中未列出的值一律拒绝；**不存在自由文本 fallback**。
- 无法进一步判定业务状态时使用已定义的 `unknown`；无法分类的安全原因使用对应的 `unknown` 原因码，不能写入 `Error.message`。
- 枚举增删必须同步更新 DB migration、TS union、TypeBox/internal contract、Outbox schema、API 校验和 fixture；审查未同步即不通过。

### 公开事件聚合范围

Worker 事件完整记录可用于内部诊断，但 `dashboard_worker_10m` 与公开 `/api/analytics/worker` **只聚合和返回**：

```text
unexpected_exit | restart_attempted | restart_succeeded | restart_failed
```

`restart_scheduled`、`spawned`、`ready`、`startup_failed` 不进入公开 Worker 指标；其中 `startup_failed` 仅安全诊断，初次启动失败不计 restart failed。

## 状态通用约定

### 模型 Attempt

| 状态 | 含义 | 成功率/超时率分母 | `completed_at` |
| --- | --- | --- | --- |
| `completed` | Provider 请求正常完成 | 是 | 本进程观察终态时必填 |
| `failed` | `model_failure_kind` 所示受控失败 | 是 | 本进程观察终态时必填 |
| `timed_out` | idle 或 total timeout | 是 | 本进程观察终态时必填 |
| `cancelled` | 用户、父任务或系统取消 | 否，单列 | 本进程观察终态时必填 |
| `interrupted` | API 观察到 Worker 异常退出 | 否，单列 | 可为 `null` |
| `unknown` | Execution/Run 已结束但 Attempt 未判定 | 否，单列 | 可为 `null` |

```text
模型成功率 = completed / (completed + failed + timed_out)
模型超时率 = timed_out / (completed + failed + timed_out)
```

分母为零时比例为 `null`，不得输出 `0%`。

### 工具

| 状态 | 含义 | 工具成功率分母 |
| --- | --- | --- |
| `completed` | 协议层执行完成 | 是 |
| `failed` | 协议层执行失败 | 是 |
| `cancelled` | 取消 | 否，单列 |
| `unknown` | 重建/恢复后无法判断 | 否，单列 |
| `queued` / `running` | 非终态 | 否 |

```text
工具成功率 = completed / (completed + failed)
```

`completed` 不表示用户任务完成，也不表示工具结果满足业务目标。

## 模型调用

模型仅支持 `provider_id + model_id` 维度。**本期不支持 Workspace 筛选、分组、归因或比较**；API 不接受 `workspaceId` 用于模型查询。

| 指标 | 口径 | 时间归属 | `null` / coverage |
| --- | --- | --- | --- |
| 请求次数 | 每次**进入 `streamTextFn(request)` / SDK Provider 调用边界**且 begin 已从 Outbox `prepared` 晋级为 `provider_invoked` 的 Attempt 计一次；重试为新 Attempt。不承诺网络层实际送达 | `started_at` | `prepared` 或 delivery gap 不创建 Fact、不计请求；gap 使模型 coverage 降级 |
| 成功率 | 见模型状态公式 | `started_at` | 分母零为 `null` |
| 输入/输出 Token | 对应字段求和 | `started_at` | 仅和非 `null`，返回 reported count |
| 总 Token | reported 优先；输入/输出都有时可派生 | `started_at` | 返回 reported/derived count |
| 缓存读取 | `cache_read_tokens` 求和 | `started_at` | 仅 `cache_comparable=1` 的样本 |
| 缓存写入 | `cache_write_tokens` 求和 | `started_at` | 仅 `cache_write_verified=1` 的样本 |
| 缓存命中率 | `sum(cache_read_tokens) / sum(input_tokens)`，仅可比样本 | `started_at` | 返回 comparable count；分母零为 `null` |
| 请求时长 | `completed_at-started_at`，分状态累计 | `started_at` | 只用两端存在且非负的可靠样本 |
| 超时率 | 见模型状态公式 | `started_at` | idle/total 分计数 |

默认页面文案为“已完成请求平均时长”，只用 `completed` 可靠样本。若展示全部可靠终态时长，必须注明包含 `completed/failed/timed_out/cancelled`，并分别返回状态样本数和时长。

### Provider 调用边界与幽灵 Attempt 取舍

- `started_at` 是 Worker 在调用 `streamTextFn(request)` 前记录于内存的 `attempt_boundary_at`；只有 SDK 调用返回或同步抛错后，Outbox 晋级成功才持久化为 Fact/DTO 的 `started_at`。它表示进入 SDK Provider 调用边界，不表示、也不推断网络报文已送达。
- 本期**不声称**外部 SDK 调用与本地 SQLite 之间存在 exactly-once 原子事务。选择“不制造幽灵请求”优先于阻断式调用前确认：调用前崩溃只留下不可投递 `prepared`；仅在新的 Outbox owner 完成 ownership handoff 后立即转为 `prepared_expired_ambiguous` gap 并清理，绝不按 TTL/年龄清理活跃 owner 的 prepared，也不计请求。
- SDK 调用返回 stream 与同步 throw 都已跨过调用边界；二者都必须立即尝试 `prepared → provider_invoked` 并写同一 `started_at`。同步 throw 随后创建 failed finish，因此仍计一次请求。
- 调用后、晋级前的进程崩溃或本地持久化故障存在不可完全消除的极窄窗口。不得将 `prepared` 自动投递或补造 Fact；可观察晋级故障立即写 `analytics_model_delivery_gap`，而 ownership handoff 发现的遗留 prepared 以 `prepared_expired_ambiguous` gap 清理，两者均将模型 coverage 标为 degraded。后者不能判断是否已调用 SDK，仍绝不估算或伪造请求；这是该取舍接受的极窄漏计风险。
- Provider 调用边界前必须已原子持久化 begin `prepared`、finish `reserved`、reservation 实体、一个 Gap 逻辑行槽位与 **64 KiB** Attempt 字节 reservation；行配额同时计三类物理行和未来槽位，单 Attempt 固定占四个单位。reservation、Gap、incident 均不是 Attempt Fact，不计 request_count、Token、时长或聚合。
- 成功 admission 后 finish/晋级/Gap 使用已预留资源，不能被普通逻辑容量阈值拒绝；真实 SQLite/I/O 故障仍按受控失败与 coverage 诊断处理。
- 每个 begin、finish、gap 的认证 transport envelope 都必须有稳定、非空、受控格式的 `delivery_event_id`；永久错误 incident 以该键幂等。`historicalLossCount` 仅定义为未修复 `confirmed_missing` incident 的计数，绝不是 Domain State 可增减标量。

### Usage 归一化

- 唯一 `normalizeModelUsage()` 读取 AI SDK finish usage 与经 fixture 验证的 Provider 补充字段；查询层不得猜字段。
- `cache_read_tokens` 仅语义已验证、且与同一 Attempt input 可比时写入，同时 `cache_comparable=1`；其他为 `null`，不等于零。
- `cache_write_tokens` 仅 Provider 专用适配验证时写入，同时 `cache_write_verified=1`；不得由输入差额推断。
- 不保存原始 usage payload、stream chunk、Provider request/response 或错误文本。

## Agent 与 Run

| 指标 | 唯一筛选条件 | 时间归属 |
| --- | --- | --- |
| Run 数与终态分布 | 每个 Run Fact 一次；completed/failed/cancelled 为常规终态，running/interrupted/unknown 单列 | `created_at` |
| 主任务 | `run_kind='user' AND parent_run_id IS NULL` | `created_at` |
| 子任务 | `run_kind='subtask'`，保留 parent 一致性校验 | `created_at` |

`manual_compaction` Fact 必须保留，但不进入主任务、子任务或 Agent 总时长。

```text
Agent 总时长对象：run_kind='user' AND parent_run_id IS NULL 的 Execution
贡献：可靠 [started_at,effective_ended_at) 与查询范围的交集
```

- 排队不计；父任务等待子任务计入父任务；子任务/manual compaction 不计，避免重复。
- 顶层任务并行允许重复累计；它不是自然时间、生产率或时间杠杆。
- 同一 Run 可恢复为多 Execution；Run 数仍一，可靠分段累加，恢复间隔不计。
- `end_time_quality='unknown'` 或 `effective_ended_at=null` 的尾段不计。
- Workspace 时长仅按此口径以 `workspace_id` 分组。

当前 queued/running 为未结束 Execution 的 `count(distinct run_id)`，包含 user/subtask/manual compaction；它与顶层时长口径不同。

## 工具

工具仅支持 `tool_name` 维度。**本期不支持 Workspace 筛选、分组、归因或比较**。

| 指标 | 口径 | 时间归属 |
| --- | --- | --- |
| 调用次数 | 每个 Tool Fact 一次，包括未开始即取消 | `created_at` |
| 按工具名统计 | 稳定 `tool_name` 原样分组，不按输入/结果/错误分组 | `created_at` |
| 成功率 | `completed/(completed+failed)` | `created_at` |
| 执行时长 | `duration_completed_at-started_at`，按状态累计 | `created_at` |

工具创建与开始跨桶时，调用、状态、时长样本始终属于 `created_at` 桶。`completed_at` 是业务/恢复状态收敛时间；只有真实观察终态才写 `duration_completed_at`，恢复/rebuild 写 `unknown` 时必须为 `null`，不得计时长。

## 用户行为

| 指标 | 口径 | 时间归属 |
| --- | --- | --- |
| 发送消息数 | `message_kind='user'` 的 Message Fact；不读取正文 | `created_at` |
| 新建会话数 | Session Fact；分别保留 `primary/subtask` | `created_at` |

没有用户 ID；默认本地工作台，可按 Workspace 筛选。

## Git

Git 指标是**当前管理 Repo 的当前可达提交历史**。Workspace 仅作 refs 发现源，绝不作为展示、筛选或聚合维度。

| 指标 | 口径 | 时间归属 |
| --- | --- | --- |
| Commit 数 | current generation membership 中每个 `(repo_id,sha)` 一次；含 Merge | Committer Date |
| 文件数 | 非 Merge `files_changed` 求和；二进制计文件 | Committer Date |
| 新增/删除行 | 非 Merge `numstat` 数值求和 | Committer Date |
| 总变更行 | 新增 + 删除 | Committer Date |

Merge 只计 Commit；二进制 `numstat='-'` 不计行数；rebase/amend 不可达 SHA 不参与 current generation。coverage 仅来自 current scan，scan 失败不切换 generation。

## Worker

| 指标 | 口径 | 时间归属 |
| --- | --- | --- |
| 异常退出 | `AgentWorkerProcessManager` 在非 `stop()` 期间实际观察 child exit | `occurred_at` |
| 自动重启尝试 | restart chain 中创建 `restart_attempt_id` 的实际启动 | `occurred_at` |
| 自动重启成功 | 同一 attempt ready 与 ready hook 后唯一结算 | ready 时间 |
| 自动重启失败 | 同一 attempt 未 ready 即失败后的唯一结算 | 失败时间 |

初次 API 启动不是 restart attempt；初次启动失败只诊断 `startup_failed`。`restart_scheduled` 不进入公开指标。API 与 Worker 同时退出、机器断电等无法观察的事件不得伪造 crash。
