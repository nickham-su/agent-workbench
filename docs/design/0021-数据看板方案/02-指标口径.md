# 指标口径

本文件是 Dashboard 统计名称、状态集合、公式、时间归属、比较、`null`、coverage 和部分结果的唯一权威。API、SQL、聚合与前端不得创造替代口径。

## 通用规则

- 所有范围型统计使用半开区间 `[from,to)`；趋势点同样使用 `[point.from,point.to)`。
- 数量和 Token 为非负整数；时长在 API 中为毫秒整数；比例为 `[0,1] | null`。
- 无分母、无样本、未覆盖、领域不可用或超预算时保留 `null`，不得转为 `0`、`-` 或缺字段。
- `agent_duration` 是从 Execution 可靠区间派生的 Domain，不是独立 Fact，也不进入监控数据量。
- `healthy` 只表示已知采集链路正常，不承诺现实世界零漏计。

## 受控展示状态

| 对象 | 合法 Analytics 展示状态 | 说明 |
| --- | --- | --- |
| Run | `running`、`completed`、`failed`、`cancelled`、`interrupted`、`unknown` | 这是 Analytics 展示状态，不改写业务 `agent_run`。 |
| Execution | `queued`、`running`、`ended` | 用于实际执行和可靠时长。 |
| Model Attempt | `running`、`completed`、`failed`、`timed_out`、`cancelled`、`interrupted`、`unknown` | 请求柱状图“其他”含 running/cancelled/interrupted/unknown。 |
| Tool | `queued`、`running`、`completed`、`failed`、`cancelled`、`unknown` | 状态分布只含终态。 |
| Message | `user`、`assistant`、`runtime`、`system`、`compaction` | 只采集元数据。 |
| Worker 历史事件 | `unexpected_exit`、`restart_attempted`、`restart_succeeded`、`restart_failed` | 其他事件仅可作实时或安全诊断。 |

## 比较合同

每个范围型指标都返回 comparison 对象：

```ts
type ComparisonResult =
  | { status: 'available'; delta: number; kind: 'relative' | 'percentage_points' }
  | { status: 'range_too_large'; delta: null; kind: null }
  | { status: 'previous_not_covered'; delta: null; kind: null }
  | { status: 'previous_zero'; delta: null; kind: null }
  | { status: 'domain_unavailable'; delta: null; kind: null }
  | { status: 'not_applicable'; delta: null; kind: null };
```

| 当前范围 | comparison |
| --- | --- |
| preset_24h / preset_7d / preset_30d | 查询紧邻前一等长周期；可用时 `status=available`。 |
| preset_90d | `status=range_too_large`。 |
| custom 且跨度 < 90 天 | 查询紧邻前一等长周期。 |
| custom 且跨度 >= 90 天 | `status=range_too_large`。 |

- 数量、Token 与时长使用 `relative`。
- 成功率、超时率、缓存命中率使用 `percentage_points`。
- 前期为零时 `delta=null`、`status=previous_zero`，不产生无穷值。
- 前期未覆盖时为 `previous_not_covered`；依赖 Domain 不可用时为 `domain_unavailable`；没有比较意义的指标为 `not_applicable`。

## 概览指标

### 监控数据量

```text
metricDefinitionVersion = dashboard_collected_fact_v1
监控数据量 = 所选范围内首次成功插入、仍在留存内的规范 Analytics Fact 数
时间归属 = collected_at
```

固定纳入：

```text
run / session / message / tool / execution / model / worker / git
```

- `agent_duration`、Rollup、Dirty、Signal、receipt、Domain State、watermark、checkpoint、membership、scan 元数据均不计。
- 每个规范 Fact 只在第一次 `INSERT` 时计一次；幂等 upsert、状态更新、Signal 重放、迟到 begin、`inferred → observed` 修正均不重复计。
- Git 按 `(repo_id, commit_identity)` 首次插入计一次。
- 定义版本和八域集合不可变。Domain 启停只前瞻性影响新 Fact 采集与完整性期待，绝不重写、移除或重新解释已采集 Fact 的历史计数。
- 后端使用 `analytics_domain_config_version.effective_at` 计算每个 Fact Domain 在 `[from,to)` 的启用时间片段。仅在启用片段要求 collection coverage、`reconciledThrough` 与无相交 coverage gap；整个范围未启用的 Domain 不构成该范围完整性要求。
- 任何启用片段未认证即为 partial 或 unavailable；不得以范围末端当前配置、部分 Domain 总数或停用片段零值冒充完整。
- API 返回 `collectionConfigVersion`、`configuredDomainsAtAsOf` 和 `configurationChangedWithinRange`。前两者仅说明 asOf 配置；范围内发生启停时最后一项为 true，不把当前配置冒充整个范围的配置，也无需 configSegments。
- asOf 未启用 Domain 从当前健康期待排除，但九 Domain health 仍显示 `disabled`。`agent_duration` 不能独立开关，始终随 execution，且不属于 Fact Domain。

### Agent 总时长

只累计：

```text
run_kind = 'user'
AND parent_run_id IS NULL
AND started_at IS NOT NULL
AND effective_ended_at IS NOT NULL
AND effective_ended_at > started_at
```

```text
Agent 总时长 = Σ duration([started_at,effective_ended_at) ∩ [from,to))
```

- 排队、子任务、`manual_compaction`、未知结束区间不计。
- 父任务等待子任务仍属于父任务；顶层任务并行可重复累计。因此它不是自然时间、推理时长、CPU 时间、生产率或时间杠杆。
- 时间归属是可靠 Execution 区间切片，不是 Run 创建时间。
- `agent_duration` 的 coverage、freshness、`reconciledThrough` 严格继承 `execution`，不能独立推进或独立认证。

### 模型请求、成功率、缓存命中率、Git Commit

分别由模型和 Git 的领域计算提供；概览不得重写公式。

## Run 与 Agent

### Run 展示状态映射

Analytics Run Fact 保存 `display_status` 与窄化 `status_quality`：

```text
status_quality = observed | inferred
```

| 条件 | `display_status` | `status_quality` | 说明 |
| --- | --- | --- | --- |
| 业务 Run 持久状态为 completed | completed | observed | 直接映射。 |
| 业务 Run 持久状态为 failed | failed | observed | 直接映射。 |
| 业务 Run 持久状态为 cancelled | cancelled | observed | 直接映射。 |
| 业务 Run 仍非终态且未有可靠中断证据 | running | observed | 非终态，不进入“已结束 Run”。 |
| 业务仍 running，且具有关联 run_id/execution_id 的 `worker_generation_exited`，或同一事务明确运行集合中的受控中断证据 | interrupted | inferred | 仅证据充分时展示，不回写业务 Run。 |
| `agent_domain_rebuilt` 或 `controlled_recovery_abandoned` 明确确认相关 Run 已不再运行但原因不可判定 | unknown | inferred | 必须关联对象或同事务明确运行集合；不回写业务 Run。 |

- observed completed/failed/cancelled 可覆盖既有 inferred interrupted/unknown。
- inferred 状态永远不得覆盖 observed 业务终态。
- 行删除、Workspace 删除、查询不到、Collector 漏扫/暂停、Analytics 采集缺失、队列满、Outbox 失败或 checkpoint stale 本身**不得**推断为 interrupted/unknown；无充分证据时保持 running 并让相关 Panel/Domain degraded。

### Run 指标

| 指标 | 定义 | 时间归属 |
| --- | --- | --- |
| 运行次数 | 每个业务 Run Fact 一次；多个 Execution 仍只算一个 Run | `created_at` |
| Run 终态分布 | 按 `display_status` 统计 | `created_at` |
| 主任务 | `run_kind='user' AND parent_run_id IS NULL` | `created_at` |
| 子任务 | `run_kind='subtask'` | `created_at` |
| 当前 queued/running | 未结束 Execution 的 `count(distinct run_id)` | live/实时，不属于历史范围 |

“全部”Run 分布包含 user、subtask、manual compaction；主任务和子任务切换按各自条件。已结束 Run 只包含 completed、failed、cancelled、interrupted、unknown；UI 可将后两者合并为“Interrupted / Unknown”，但不能混入 completed/failed/cancelled。running 不进入已结束总数。

## Message 与压缩摘要

- 每个 `message_id` 仅计一次，按 `created_at` 归属。
- 消息分类统计所有受控 type：user、assistant、runtime、system、compaction。
- Fact 只保存稳定 ID、类型、完成状态、来源 Run、安全时间和 compaction 分类质量；不保存正文、part、Reasoning 或工具参数。

| 指标 | 定义 |
| --- | --- |
| User 消息 | `message_kind='user'` 的 Message Fact 数 |
| Assistant 消息 | `message_kind='assistant'` 的 Message Fact 数 |
| 手动压缩上下文 | `type='compaction' AND status='completed'`，且来源 Run 的 `run_kind='manual_compaction'` |
| 自动压缩上下文 | `type='compaction' AND status='completed'`，且来源 Run 的其他已知 `run_kind` |

只有实际 completed compaction 才计压缩。来源 Run 缺失/尚未采到时为 unknown，既不计 manual 也不计 auto，并使相关分类结果 partial/unavailable；不得猜测。

## Tool

| 指标 | 定义 | 时间归属 |
| --- | --- | --- |
| 工具调用 | 每个 Tool Fact 一次，包含未开始即取消 | `created_at` |
| 工具明细 | 按 `agent_message_part.tool_name` 的安全值分组 | `created_at` |
| 调用成功率 | `completed / (completed + failed)` | `created_at` |
| 完成平均时长 | completed 的可靠 `completed_at-started_at` 平均值 | `created_at` |

- 成功率分母为零时为 `null`。
- completed 只表示协议层执行完成，不代表用户任务成功或结果符合预期。
- 工具状态分布只统计终态调用：`completed + failed + cancelled + unknown`；queued/running 不进入。
- unknown 或缺少可靠两端时间的样本不进入时长。
- `call_part_id` 正常由非空唯一外键关联到 `agent_message_part.id`；若安全名称关联异常，保留调用计数、名称为 unavailable 并降级 Tool Domain，绝不构造名称。

## 模型

### Attempt 与状态

模型请求是一次已越过 `streamTextFn` / SDK Provider 调用边界的 Attempt，不承诺网络报文送达。

- 每次调用和每次重试都是独立 Attempt。
- Analytics 不是调用前置条件；不存在 `prepared` 业务前置状态。
- invoked/finished Signal 是 best-effort；finished 可在 invoked 丢失时独立建立 Fact。
- 请求、状态、Token、缓存和时长均按 `started_at` 归属。

```text
成功率 = completed / (completed + failed + timed_out)
超时率 = timed_out / (completed + failed + timed_out)
其他 = running + cancelled + interrupted + unknown
```

成功率或超时率分母为零时为 `null`。其他状态不进入两个比例分母，但“其他”必须进入请求趋势堆叠，使各柱合计等于请求数。

### Token、缓存与时长

| 指标 | 定义 | 覆盖/空值 |
| --- | --- | --- |
| 输入 Token | `sum(input_tokens)` | 只累加非 null，返回 `input_reported_count` |
| 输出 Token | `sum(output_tokens)` | 只累加非 null，返回 `output_reported_count` |
| 总 Token | reported total 优先；输入/输出齐备时可 derived | 返回 reported/derived count |
| 缓存读取 | `sum(cache_read_tokens)` | 仅 `cache_comparable=1` |
| 缓存命中率 | `sum(cache_read_tokens) / sum(input_tokens)` | 仅可比样本，分母零为 null |
| 已完成请求平均时长 | completed 可靠 `completed_at-started_at` 平均 | 无样本为 null |

```text
输入 Token 覆盖率 = input_reported_count / request_count
输出 Token 覆盖率 = output_reported_count / request_count
总 Token 覆盖率 = (total_reported_count + total_derived_count) / request_count
输入缓存覆盖率 = cache_comparable_count / request_count
```

分母零时覆盖率为 null。Provider 未提供 usage、或缓存不具可比性时必须保持 null，绝不按零。

## Git

Git 指标表示当前受管理 Repo 的当前可达提交历史；Workspace 只用于发现 refs，不是筛选或展示维度。

| 指标 | 定义 | 时间归属 |
| --- | --- | --- |
| Commit | current generation 中每个 `(repo_id, commit_identity)` 一次，含 Merge | Committer Date |
| 非 Merge Commit | 父数不大于一 | Committer Date |
| 变更文件 | 非 Merge `files_changed` 求和，二进制计文件 | Committer Date |
| 新增/删除行 | 非 Merge `numstat` 数值分别求和 | Committer Date |

- Merge 只计 Commit；二进制 `numstat='-'` 不计行；rebase/amend 后不在 current generation 的 Commit 不参与统计。
- Git 行数只表示提交变更规模，不代表质量、效率或个人产出。
- Git 部分 coverage 时返回已知部分值/下界，不能伪装完整；详见[Git 采集方案](./06-Git采集方案.md)。

## Worker

| 历史指标 | 定义 | 时间归属 |
| --- | --- | --- |
| 异常退出 | ProcessManager 在非受控 stop 期间实际观察 child exit | `occurred_at` |
| 重启次数 | `restart_attempted` 数 | `occurred_at` |
| 重启成功 | 同一 attempt ready 与 ready hook 后唯一结算 | ready 时间 |
| 重启失败 | 同一 attempt ready 前失败后的唯一结算 | 失败时间 |

初次启动不是 restart attempt；初次启动失败不计 restart failed。已恢复运行不抵消重启告警。

Worker 实时面板使用同一 AgentRunner 外层调度 snapshot：

```text
外层运行中 = activeCount
外层排队 = queue.length
配置槽位 = concurrency
槽位占用 = activeCount / concurrency
```

nested Execution 不增加 `activeCount`，不能算额外槽位。snapshot 过期时整组 stale；local fallback 单独标识，不与 Agent Worker 槽位合并。
