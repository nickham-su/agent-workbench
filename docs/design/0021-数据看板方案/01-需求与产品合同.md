# 需求与产品合同

## 产品边界

Dashboard 是 Workbench 壳内的本地系统统计页，用于回看 Agent、模型、工具、消息、Git 和 Worker 的使用与可靠性。

它不是用户绩效、生产率、CPU 或代码质量评估，也不是 Prompt、回复、工具结果、终端内容或 Git 内容的检索页。系统整体统计不提供 Workspace、Provider、Model、Repo、作者或路径筛选；Provider/Model 仅可作为响应内系统整体分组。

## 单次范围查询

范围刷新唯一使用：

```text
POST /api/analytics/dashboard/query
```

请求含受控 `rangeKind`、IANA `timezone`，custom 才含已解析 UTC Unix ms 的 `from/to`。服务端一次生成 `rangeId/from/to/asOf`，所有范围型卡片、趋势、分布和表格共享这组范围；不建设有状态 rangeId 上下文。

- custom 最大 366 天，必须 `from < to` 且均为安全整数。
- API 不接收本地墙上时间。客户端解析失败、DST 不存在/歧义时间时不请求；服务端用 IANA timezone 做显示分桶。
- 非法请求是受控 HTTP 400，不附 range 元数据；Analytics 整体不可用是受控 HTTP 503。合法请求一定为 200，单 Domain 问题仅在对应结果中表示。
- Git 180 本地日热力图、Worker live snapshot、Domain health 随同一个 200 响应返回，但携带自身的时间戳语义。

## 结果、比较与部分数据

- 每个卡片、趋势、分布和表格是 `MetricResult<T>` 或 `PanelResult<T>` 判别联合。
- available 必为完整非 null 数据；partial 必为已知非 null 数据、`dataIncomplete=true` 和受控 partial reason；unavailable 必为 null 和受控 unavailable reason。
- 一个 Domain 出问题不能让成功响应整包丢失，不能静默缩短其它指标范围，也不能用未认证零值掩盖缺口。
- comparison 始终存在。24h/7d/30d 与 custom 小于 90 天比较紧邻前期；90d 与 custom 不小于 90 天为 `range_too_large`。数量/时长为相对百分比，比例为百分点；previous zero/not covered/domain unavailable 都返回受控状态和 null delta。

## 概览

概览固定卡片：监控数据量、Agent 总时长、模型请求、请求成功率、缓存命中率、Git Commit。数据健康完整显示：

```text
model / run / execution / agent_duration / tool / message / session / worker / git
```

范围结果共享完整性约束；Worker snapshot 是实时例外，不得伪装为历史利用率。

## 监控数据量

不可变定义：

```text
metricDefinitionVersion = dashboard_collected_fact_v1
Fact Domain = run / session / message / tool / execution / model / worker / git
时间归属 = Fact 首次 collected_at
```

- `agent_duration`、Rollup、Dirty、Signal、receipt、checkpoint、state、watermark、membership、scan 元数据不计。
- Domain 启停只前瞻性影响新 Fact 采集和完整性期待；不得重算、移除或重新解释留存内已采集 Fact。
- 后端按 `analytics_domain_config_version.effective_at` 为每个 Fact Domain 计算 `[from,to)` 内启用片段。只对启用片段要求 collection coverage、水位和无相交 gap；任一启用片段不能认证时，指标为 partial/unavailable；整个范围未启用则不构成完整性要求。
- API 返回 `collectionConfigVersion`、`configuredDomainsAtAsOf` 和 `configurationChangedWithinRange`。前两者仅是 asOf 诊断，不能替代历史启用片段；最后一项仅提示 UI，无需返回分段。
- asOf 未启用 Domain 从当前健康期待排除，但 health 仍显示 disabled；agent_duration 始终跟随 execution，且不属于监控数据量 Fact Domain。

## 隐私与不侵入

Analytics 只能保留稳定安全 ID、时间、受控状态、Provider/Model、工具名、Repo 安全 ID、Token 数值、时长、次数与 Git 聚合统计。

禁止进入 Analytics DB、IPC、Outbox、日志、API、UI 或 fixture：正文、Reasoning、工具参数/结果、终端 I/O、原始错误、路径、真实 SHA、Commit Message、Diff、remote/ref、凭证或绝对工作区路径。

Analytics 不得改变业务结果、状态、调用顺序或成功条件。队列满、Outbox/checkpoint/Collector 失败、子进程故障和查询超时可导致统计降级或已知漏计，但不得阻断业务。

## 历史与留存

不做旧业务数据迁移、兼容 union 查询或推断回填。非 Git 范围早于 availableFrom 时展示未覆盖，不补零；Git scan 可自然取得当前可达历史。

`retentionFloor` 是业务事件时间查询边界。Model/Tool/Message Rollup 依 `bucket_end <= retentionFloor` 删除，collected Rollup 按自身 collected-at 桶删除，receipt 按 `committed_at` 删除。未可靠结束的 Execution/Model 是 open Fact 例外，不能仅按首次 collected_at 删除。
