Workspace 环境变量

为 bash 工具和终端配置同一套环境变量，仅作用于当前 Workspace。

启用变量名值备注操作

全部为虚构示例。本原型仅在内存中模拟保存，刷新后恢复初始数据。

生效范围

bash 工具

下一次调用使用新配置。
运行中的命令保持原环境。

终端

新建会话使用新配置。
已有会话重连不会更新。

配置规则

  • bash 和终端共享当前 Workspace 的配置，不修改服务进程环境。
  • 空字符串是合法值，与未配置不同。
  • 删除或停用仅移除覆盖，回到基础环境继承，不等同于 unset。
  • 值按字面处理，不展开 $PATH，不执行命令替换。
  • AWB_* 和系统托管的 Git 鉴权变量受保护，不允许覆盖。
安全提醒
命令可以读取并输出变量；请勿将敏感值写入日志。

本原型不保存真实配置，也不实际执行 bash 或创建终端。
